# wiliheng-site

Static site for **Yangjiang Wiliheng Knives Co., Ltd** — an OEM/ODM knife and kitchenware
factory in Yangjiang, Guangdong, China (manufacturing since 2018).

- Company site: <https://wiliheng.com/>
- B2B catalogue (9 languages): <https://wiliheng.com/b2b/>
- Product photos with reference codes: <https://wiliheng.com/b2b/photos/>
- Product catalogue PDF: <https://wiliheng.com/Wiliheng-Product-Catalogue.pdf>

Buyers: importers, distributors, houseware brands and retail chains. MOQ from 500 pcs per model.

_This repository hosts the published static output; content is generated from the factory's
production system._
